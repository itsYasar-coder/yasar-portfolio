SQL joins I actually use for dashboards

Sep 2026 · 5 min

Only 2 joins cover 90%

INNER JOIN — when I want only matched rows. Example: bills + products where product exists.

LEFT JOIN — when I want all bills even if product mapping is missing. Missing ones show NULL, which tells me mapping needs fixing.

-- top products, keep all sales
SELECT p.name, SUM(s.amount) AS sales
FROM sales_clean s
LEFT JOIN products p ON p.code = s.product_code
GROUP BY 1 ORDER BY 2 DESC LIMIT 5;
Rule: dashboard numbers must match Excel pivot first. Then add filters.
