Building a sortable React table (no library)

Aug 2026 · 6 min

Pattern

State for sort key + direction, useMemo for sorted copy. Don't sort original array — copy with [...data] first.

const [key, setKey] = useState('date');
const [dir, setDir] = useState(1);
const rows = useMemo(() => {
  return [...data].sort((a,b) =>
    a[key] > b[key] ? dir : -dir);
}, [data, key, dir]);
For 1000+ rows add search filter before sort, and keep components small.
