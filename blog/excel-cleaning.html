How I clean 5k Excel rows without losing my mind

Oct 2026 · 4 min

My checklist

  1. Copy raw file first — never clean original.
  2. Remove duplicates (Data → Remove Duplicates), note count.
  3. TRIM + CLEAN for extra spaces, PROPER for names.
  4. Fix dates: Text to Columns → YYYY-MM-DD.
  5. XLOOKUP for mapping, not VLOOKUP — handles new columns.
  6. Pivot to verify totals match raw.
Tip: I keep a “changes” sheet — what I removed, why. Client trusts the file more.

Common mistakes

Merged cells, hardcoded totals, dates as text. Fix these first or every formula breaks later.
